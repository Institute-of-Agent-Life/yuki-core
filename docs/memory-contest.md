# Preserve an actual disputed memory

Normal sequence: read the accessible current Person fact, then apply an original contest request. Keep the fact active and retain its text; mark its conflict state, record the source evidence, the revision and the original operation together. If an alternative is supplied, preserve both distinct claims. A review marker cannot silently replace the original evidence.

Fault sequence: stale reads, another Person, erased or unreadable evidence, an inactive source, and an interrupted alternative write must not change either fact. The same original operation replays its first receipt. Distinguish an active contested assertion from a retracted, superseded or erased fact in reads and retrieval.
