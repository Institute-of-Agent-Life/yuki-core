# Same native QQ input for the slice

Normal sequence: freeze the ordered QQ packets for the named E13 arrivals once, then admit those bytes through the v4 OneBot normalizer for A/B and the native WebSocket for C. The model, gateway send and committed outbound event are observed separately. Compare identity, mentions, destination, recipient and text before interpreting latency.

Fault sequence: a different packet digest, omitted send part, missing committed event or different model-facing material blocks performance comparison. Identical ingress cannot establish full tool parity or comparable resource use by itself.

For a real QQ at-segment targeting a known bot Assignment at event time, the old model sees `Agent/@{account:…}` in the header and `@Agent` in the text. Literal marker text, an unresolved or foreign account and a stage opened after the event are not proof of a bot mention. The raw admitted envelope and its Unicode offsets remain available to diagnostics.

Reproduce the Rust replay with `python ci/check.py CORE-040 --out artifacts/CORE-040/<new-run>`. It starts the native QQ/Chat owner, records the four gateway sends and eight physical requests, and compares the model input with the independently recorded A/B projection. The case also rejects a corrupted stimulus hash and detects an omitted private send. Identity comparison checks UUID roles while preserving the exact visible nickname, time, mention, text, current context and system/runtime prefix.

To regenerate the original pair, freeze one file using `python -m bench.native_arrivals frames.jsonl --count 4`. With the isolated v4 environment and the owner's SQLite 3.46.0 library, run `bench/legacy.py A` and `bench/legacy.py B` with `--checkout`, `--out`, `--library`, `--count 4`, `--frames frames.jsonl` and the printed `--frames-sha256`. A requires the unmodified pinned source, B the exact patch stored in `bench/controls/b.patch.gz`. The two arms' original run, wire sample, timing stream, gateway events and JUnit hashes are in `fixtures/oracle/v4/native-group-contract.json`. On macOS select the private library with DYLD_LIBRARY_PATH; Linux uses LD_LIBRARY_PATH. The tests' HTTP endpoint is local.

The first diagnostic put native messages before the v4 actor Assignment began. Both old applications refused admission as nonhuman and made zero model requests; the earlier Rust setup had a different Assignment interval. The corrected fixture uses the old database's actor epoch and creates its bot Presence at that same instant on both sides. All three then received identical packets; the old native header/body and corrected Rust projection agree. The four observed replies and the sampled original request do not establish full E13 equivalence. See `slice-decision.json` for missing/extra/changed declarations, Chat knobs and the follow-up send result shape.
