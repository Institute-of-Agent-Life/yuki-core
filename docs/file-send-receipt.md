# File and caption receipt

Send a pinned file version and a caption to the original QQ recipient. Acknowledge the upload and the text separately. The next physical model request should receive one aggregate result with two ordered children, each carrying its actual original delivery event. The aggregate carries the immutable file identity and the two counts. Each paired device must still download the recorded bytes after the original workspace path changes.

If either acknowledgement is missing, retain the actual confirmed, unknown and unattempted states. Reading the result must never deliver a part again. If access to the delivered file or caption changes after the model has read it, refuse a subsequent dispatch that would reuse the old body.
